# SensibleMD v0.1 Acceptance Checklist

## Automated

- [x] Production renderer builds with `npm run build`.
- [x] Core and corpus regression suite passes with `npm test`.
- [x] Markdown parsing, semantic navigation, search, pagination, diagnostics, positions, and collection links have fixture coverage.
- [x] Reader-first bundle excludes CodeMirror until Writing or Split mode is opened.
- [x] Electron main and preload scripts pass Node syntax checks.
- [x] Native Save and Save As use sibling temporary files followed by atomic replacement.
- [x] Dirty desktop buffers create bounded latest/previous recovery snapshots outside user Markdown.
- [x] Hostile Markdown fixtures verify scripts do not execute and dangerous URI schemes do not render as active links.

## Implemented Prototype Workflows

- [x] Open, read, edit, save/download ordinary Markdown files.
- [x] Navigate headings, paragraphs, links, images, tables, and code blocks through semantic commands.
- [x] Search a document or collection and return to the search origin.
- [x] Read continuous, single-page, and spread presentations with keyboard page turns.
- [x] Open a Markdown collection, navigate chapters, and follow relative chapter links.
- [x] Persist semantic reading positions, bookmarks, reader preferences, and reading presentation locally.
- [x] Report accessible-authoring findings for headings, links, images, code fences, lists, and table headers.
- [x] Handle desktop external file changes without silently discarding dirty source.
- [x] Offer explicit recovery restore/discard behavior for unsaved crash snapshots.

## Required Manual Release Checks

- [ ] Package and launch the macOS artifact.
- [ ] Test native open, direct save, Save As, reopen, and recent files in the packaged app.
- [ ] Run keyboard-only reader, editor, search, book-mode, and conflict scripts.
- [ ] Run the VoiceOver scripts on macOS and record results.
- [ ] Test the external-change conflict flow with a real file on disk.

## v0.1 Limitations

- Pagination groups semantic blocks by estimated word capacity; it is not yet measured DOM pagination.
- Position recovery supports ID, fingerprint, text anchor, heading, and document fallback; it is not yet optimized for large-document reconciliation.
- Structural search scopes are implemented in the semantic API; the reader UI currently exposes document and collection scope controls.
- Cross-platform assistive-technology validation remains a manual release requirement.
